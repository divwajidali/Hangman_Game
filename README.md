# 🎮 Hangman Game in Python

A simple and beginner-friendly Hangman game made using Python.  
This project is console-based and helps beginners practice Python logic, loops, lists, dictionaries, and conditional statements.

---

# 📌 Features

✅ Multiple Word Categories  
✅ Random Word Selection  
✅ Lives System  
✅ Win & Lose Conditions  
✅ Input Validation  
✅ Beginner Friendly Logic  
✅ Console-Based Gameplay  

---

# 🗂 Categories Included

- Easy Words
- Medium Words
- Hard Words
- Animals
- Countries
- Technology
- Fun Words

---

# 🕹 How to Play

1. Run the program.
2. Choose a category.
3. The game will randomly select a word.
4. Guess one letter at a time.
5. Correct letters will appear in the word.
6. Wrong guesses reduce your lives.
7. Guess the full word before your lives become 0.
